# Quickstart Validation: Library & Chord Bank

1. Sign in (profile from 001).
2. Open Library → paste a short chart with `G C D Em` → save as text item.
3. Extract chords → review → accept → Chord bank shows 4 entries.
4. Reload → library item + bank persist.
5. Practice this song → change difficulty + transpose → log practice with song reference.
6. Try unsupported/huge file → clear error.
7. Delete library item with confirm → item gone; bank entries remain with optional stale source.
